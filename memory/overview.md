# Uniflow Overview

## Mission

Uniflow is a university management ecosystem consisting of:

- Public landing platform
- University administration portal
- Lecturer mobile application
- Student mobile application

## Problem

Universities struggle with:

- Timetable communication
- Real-time class updates
- Resource sharing
- Student notifications

## Solution

A centralized platform that allows universities, lecturers and students to manage academic activities in real time.

## Current Stage

Mobile App: In Development
